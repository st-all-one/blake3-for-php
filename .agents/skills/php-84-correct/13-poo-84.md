# Programação Orientada a Objetos no PHP 8.4

Este documento complementa `04-poo-baseline.md` com os recursos de OO modernos
disponíveis até o PHP 8.4: atributos (8.0), enums (8.1), promoção de
propriedades (8.0), propriedades `readonly` (8.1) e classes `readonly` (8.2),
constantes `final` (8.1) e constantes em traits (8.1), `WeakMap` (8.0),
`#[\Override]` (8.3), e os **novos recursos do 8.4**: *property hooks*,
*visibilidade assimétrica de propriedades* e *lazy objects*.

Todo o código é válido em PHP 8.4.

## 1. Atributos `#[...]` (PHP 8.0)

Atributos substituem docblocks para metadados estruturados e reflectivos.

```php
#[Atributo]
#[Rota('/usuarios', metodo: 'GET')]
class ControladorUsuarios
{
    #[Validar('email')]
    public function criar(): void {}
}
```

- Declarar a classe de atributo com `#[\Attribute]` (com flags de alvo opcionais):

```php
namespace App\Atributos;

#[\Attribute(\Attribute::TARGET_METHOD | \Attribute::TARGET_CLASS)]
class Rota
{
    public function __construct(public string $caminho, public string $metodo = 'GET') {}
}
```

- Leitura via Reflection:

```php
$ref = new ReflectionClass(ControladorUsuarios::class);
foreach ($ref->getAttributes(Rota::class) as $attr) {
    $rota = $attr->newInstance();
    echo $rota->caminho; // '/usuarios'
}
```

### `#[\Override]` (PHP 8.3)

Marca um método que **deve** sobrescrever um método da classe pai; se não
sobrescrever, erro em tempo de compilação.

```php
class Base
{
    public function processar(): void {}
}

class Filha extends Base
{
    #[\Override]
    public function processar(): void {} // ok: sobrescreve
}
```

### `#[\Deprecated]` (PHP 8.4)

Marca função, método ou constante de classe como obsoleta. Emite
`E_USER_DEPRECATED` (não `E_DEPRECATED`) quando usada. Aceita mensagem e
"desde" (since).

```php
class Legado
{
    #[\Deprecated('Use novaApi() em vez disso', since: '2.0')]
    public function apiAntiga(): void {}
}
```

- Ver mais em `17-logs-84.md`.

## 2. Enums — unit e backed (PHP 8.1)

### Unit enum (sem valor)

```php
enum Status
{
    case Pendente;
    case Ativo;
    case Inativo;
}

$estado = Status::Ativo;
echo $estado->name; // 'Ativo'
```

### Backed enum (int/string)

```php
enum Nivel: string
{
    case Baixo = 'low';
    case Medio = 'mid';
    case Alto = 'high';

    public function rotulo(): string
    {
        return match ($this) {
            self::Baixo => 'Baixo',
            self::Medio => 'Médio',
            self::Alto => 'Alto',
        };
    }
}

$n = Nivel::from('mid');      // Nivel::Medio
$n2 = Nivel::tryFrom('x');    // null (não lança)
```

- `BackedEnum::from()` lança `ValueError` se o valor não existir;
  `tryFrom()` retorna `null`.
- `enum_cases(Nivel::class)` retorna array de casos (função global, 8.1+).
- Enums podem implementar interfaces e ter traits, mas **não** podem estender
  classes nem ter propriedades `static` mutáveis.
- Constantes em enums: sim, desde 8.1.

```php
interface Rotulavel { public function rotulo(): string; }
enum Cor: string implements Rotulavel { /* ... */ }
```

```php
        public string $nome,
        public readonly int $id,
    ) {}

```

## 4. Propriedades `readonly` e classes `readonly` (8.1/8.2)

```php
readonly class Snapshot
{
    public string $estado;
    public int $timestamp;

    public function __construct(string $estado, int $timestamp)
    {
        $this->estado = $estado;
        $this->timestamp = $timestamp;
    }
}
```

- Propriedade `readonly` individual: `public readonly int $x`.
- Classe `readonly`: todas as propriedades são implicitamente readonly.
- Regras detalhadas em `11-tipagem-84.md` (seções 9).

## 6. `WeakMap` (PHP 8.0)

Mapa cujas chaves são objetos mantidos por **referência fraca**: quando o
objeto-chave não tem mais referências fortes, a entrada é removida
automaticamente pelo GC, evitando vazamento de memória em caches.

```php
$wm = new WeakMap();

$obj = new stdClass();
$wm[$obj] = ['meta' => 'dados'];

// Enquanto $obj existir: $wm[$obj] disponível.
// Quando $obj for coletado, a entrada some sozinha.
unset($obj);
// $wm agora está vazio. GC dependente.
```

- `WeakReference` (7.4) é a primitiva de referência fraca a um único objeto;
  no 8.4 ela passa a expor melhor info de debug (objeto referido ou `null`).

## 7. Lazy Objects (PHP 8.4)

Permitem adiar a inicialização de um objeto até que ele seja efetivamente
acessado — útil para ORMs, DI containers e carregamento preguiçoso de
dependências. Usa `ReflectionClass::newLazyGhost()` / `newLazyProxy()`.

```php
class ServicoPesado
{
    public function __construct(private int $id) {}

    public function operar(): string
    {
        return "operando $this->id";
    }
}

$inicializador = static function (ServicoPesado $fantasma): void {
    // Busca dados/dependências sob demanda e inicializa
    $fantasma->__construct(42);
};

$ref = new ReflectionClass(ServicoPesado::class);
$obj = $ref->newLazyGhost($inicializador);

// Ainda não inicializado; o inicializador roda no primeiro acesso:
echo $obj->operar(); // dispara $inicializador, depois opera
```

- `newLazyProxy()` cria um proxy que delega a um objeto real criado no acesso.
- Métodos de reflection relacionados (8.4): `isUninitializedLazyObject()`,
  `initializeLazyObject()`, `markLazyObjectAsInitialized()`,
  `getLazyInitializer()`, `resetAsLazyGhost()` / `resetAsLazyProxy()`,
  `ReflectionProperty::skipLazyInitialization()`,
  `ReflectionProperty::setRawValueWithoutLazyInitialization()`.
- Constantes: `ReflectionClass::SKIP_INITIALIZATION_ON_SERIALIZE`,
  `ReflectionClass::SKIP_DESTRUCTOR`.

## 8. Property Hooks (PHP 8.4)

Propriedades podem ter lógica associada aos hooks `get` e `set`. Um hook `get`
sem corpo de backing gera uma **propriedade virtual** (sem valor armazenado).

```php
class Pessoa
{
    // Propriedade virtual (sem backing value)
    public string $nomeCompleto {
        get => $this->nome . ' ' . $this->sobrenome;
    }

    // Todo write passa pelo hook; o resultado é o que é armazenado
    public string $nome {
        set => ucfirst(strtolower($value));
    }

    // Hook set que grava ele mesmo no backing value
    public string $sobrenome {
        set {
            if (strlen($value) < 2) {
                throw new InvalidArgumentException('Muito curto');
            }
            $this->sobrenome = $value;
        }
    }

    public function __construct(public string $nome, public string $sobrenome) {}
}

$p = new Pessoa('peter', 'Peterson');
echo $p->nomeCompleto; // 'Peter Peterson'
// $p->nomeCompleto = 'x'; // Error: propriedade é read-only (virtual)
```

- Hooks podem ser tipados; o tipo deve ser compatível com a propriedade.
- `get` virtual não pode ser combinado com `set` que tenta gravar num backing
  inexistente. Pode-se ter apenas `get` (virtual read-only) ou apenas `set`.
- Funciona com promoção de construtor? Não diretamente no mesmo parâmetro; hooks
  aplicam-se a propriedades declaradas.

## 9. Visibilidade assimétrica de propriedades (PHP 8.4)

A visibilidade de **leitura (get)** pode ser mais ampla que a de **escrita
(set)**. A visibilidade de get não pode ser mais estrita que a de set.

```php
class Exemplo
{
    // get: public, set: protected
    public protected(set) string $nome;

    public function __construct(string $nome)
    {
        $this->nome = $nome; // ok: set é acessível na classe
    }
}

$e = new Exemplo('Ana');
echo $e->nome;      // ok (public get)
// $e->nome = 'B';  // Error: set é protected
```

- Formas: `public protected(set)`, `public private(set)`,
  `protected private(set)`.
- Combina com `readonly`? `readonly` já restringe set a uma única vez; visibilidade
  assimétrica controla *quem* pode setar. Ex.: `public private(set) readonly
  string $id` (leitura pública, escrita apenas na própria classe, uma vez).

## 10. Classes anônimas (PHP 7.0)

```php
$logger = new class implements LoggerInterface {
    public function log(string $msg): void { error_log($msg); }
};
```

## 11. Métodos mágicos e serialização (modernos)

- `__serialize()` / `__unserialize()` (PHP 7.4) dão controle fino sobre
  serialização, substituindo o par `__sleep`/`__wakeup` em muitos casos.

```php
class Entidade
{
    public function __serialize(): array
    {
        return ['id' => $this->id, 'nome' => $this->nome];
    }

    public function __unserialize(array $data): void
    {
        $this->id = $data['id'];
        $this->nome = $data['nome'];
    }
}
```

- Outros mágicos: `__get`, `__set`, `__call`, `__callStatic`, `__isset`,
  `__unset`, `__toString`, `__invoke`, `__clone`, `__debugInfo`, `__get`
  (dinâmico), `__set_state` (para `var_export`).

## 12. Exceções

Em PHP 8.4 o sistema de exceções é o moderno (desde 7.0+): `Throwable`,
`Exception`, `Error`, `TypeError`, `ValueError`, `ArgumentCountError`,
`ArithmeticError`, `DivisionByZeroError`, `UnhandledMatchError`,
`AssertionError`, etc. Use tipos de exceção específicos.

```php
try {
    perigoso();
} catch (ValueError $e) {
    // tratamento específico
} catch (Throwable $e) {
    // fallback
}
```
